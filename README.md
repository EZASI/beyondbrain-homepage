# BeyondBrain — 3Dバーチャルショールームのコーポレートサイト

株式会社BeyondBrainのコーポレートホームページです。八角形のショールームの壁ごとに事業を一つずつ展示します。来訪者は部屋の中に立ち、下部のナビゲーションか、画面を左右にドラッグして、壁から壁へ向きを変えます。展示物を選ぶと手前に取り出され、説明カードと問い合わせリストへの追加ボタンが出ます。

## 起動

```bash
npm install
npm run dev
```

## 本番ビルド

```bash
npm run build
npm run preview
```

## テスト

```bash
npm test
```

問い合わせの送信先（`api/inquiry.js`）を確かめます。メール送信サービスは代役に差し替えているので、実際のメールは送られません。

## 主な実装

- React + TypeScript + Vite
- Three.jsによる手続き生成のショールーム（板張りの床、上から照らした壁、隅の竹と行灯、什器、23点の展示物、キャンバス描画のテクスチャ）。外部の3Dモデルや画像は使っていません
- カメラは目の高さで水平に構え、展示から離れて立ちます。床が画面の下3分の1ほどを占め、パソコンでは壁の両隅まで見えます。床を多く見せるために、建築写真のあおり（レンズシフト）と同じ方法で絵を上にずらしています
- 壁ごとのカメラ位置は画面の縦横比から計算。縦長の画面では什器を2列に組み替えます。最初の画面では、見出しの文章が床の上に収まるように文章の高さを測り、背の低い画面では後ろに下がって立ちます（壁のロゴがヘッダーに重なる場合はロゴを出しません）
- 左右のドラッグで部屋を回せます。指を離すと、向かっていた壁で止まります。素早く払うと隣の壁へ進みます
- 描画は動きがあるときだけ行い、影も光源が動いたときだけ更新します。動きが遅れ続ける端末では、一度だけ解像度と影の細かさを下げます
- 問い合わせはサイト内のフォームから送信します（下の「お問い合わせフォーム」を参照）。問い合わせリストはブラウザ内に保存し、フォームと一緒に送られます
- `#fa-parts` などのハッシュで各壁に直接リンクできます（旧サイトの `#about` `#company` `#contact` は会社情報シートを開きます）
- WebGL2が使えない環境では、同じ内容の通常ページを表示します
- キーボード操作（←→で移動、Escで閉じる）、`prefers-reduced-motion`への対応
- 日本語・英語の切り替え。左上の「JP / EN」で選べ、選んだ言語はブラウザに保存されます
- Google Fontsの日本語・英語フォント（OFLライセンスは`public/fonts/`に同梱）

## 構成

- `src/showroom/content.ts` — 事業・展示物・会社情報・ボタン類の文言（日本語と英語）。内容の変更はここだけで足ります
- `src/showroom/ShowroomScene.ts` — 3Dシーン、部屋、カメラの構図と移動、ドラッグでの回転、展示物の選択、描画
- `src/showroom/fixtures.ts` / `items.ts` — 什器と展示物の形
- `src/showroom/props.ts` — 隅に置く竹の鉢と行灯
- `src/showroom/kit.ts` / `parts.ts` — マテリアル、テクスチャ、形状の組み立て
- `src/components/Showroom.tsx` — ナビゲーション、カード、会社情報シート
- `src/components/InquiryForm.tsx` — お問い合わせフォームと送信後の表示
- `src/showroom/inquiry.ts` / `useInquiry.ts` — 入力内容の確認、送信、送信状態
- `api/inquiry.js` — 問い合わせをメールで会社に届けるVercelの関数
- `tests/` — `api/inquiry.js` のテスト
- `src/showroom.css` / `src/index.css` — スタイル
- `public/` — ロゴ、favicon、フォントライセンス

## お問い合わせフォーム

右上のリストのボタン、最初の画面の「まずは話す」、会社情報シートの「お問い合わせフォームを開く」から開きます。お名前とメールアドレスが必須で、問い合わせリストが空のときはご用件も必須です。

送信すると `POST /api/inquiry` が呼ばれ、Resend経由で会社のアドレスにメールが届きます。返信先（Reply-To）は来訪者のアドレスなので、そのメールに返信すれば相手に届きます。来訪者には受付番号（`BB-年月日-4文字`）を表示します。来訪者への自動返信メールは送りません。

Vercelのプロジェクトに次の環境変数を設定します。

| 変数 | 必須 | 内容 |
| --- | --- | --- |
| `RESEND_API_KEY` | はい | ResendのAPIキー。未設定の間はフォームから送信できません |
| `INQUIRY_NOTIFY_EMAIL` | いいえ | 届け先。既定は `contact@beyondxbrain.com` |
| `INQUIRY_FROM_EMAIL` | いいえ | 差出人。Resendで認証済みのドメインのアドレス。既定は `BeyondBrain Showroom <inquiry@beyondxbrain.com>` |

`GET /api/inquiry` を開くと、送信できる状態かどうかが分かります（`{"ok":true,"delivery":"email"}` なら送信可、`"none"` ならキー未設定）。キーの値は返しません。

送信できなかったとき（キー未設定、Resendの障害、通信エラーなど）は、その旨を表示し、入力内容を残したまま「メールを作成」と「内容をコピー」を出します。届いていない問い合わせを「送信しました」と表示することはありません。

迷惑送信への備えは、同一サイトからの送信のみ受け付けること、人には見えない入力欄（プログラムだけが埋める）、同じ送信元からの回数制限（10分に6件まで）の三つです。入力内容はサーバーに保存せず、ログにも書きません。

## 表示言語

最初に表示する言語は、次の順で決まります。

1. アドレスの `?lang=ja` / `?lang=en`
2. 前回「JP / EN」で選んだ言語
3. ブラウザの言語設定（日本語なら日本語、それ以外は英語）

文言は `content.ts` の `t('日本語', 'English')` に並べて書いてあります。片方だけを変えると、もう片方は古いまま残ります。展示室内の画面やパッケージの絵（ゲームのタイトルなど）は言語によって変わりません。利用規約などの法務ページは日本語のみです。

`index.html` のタイトルや説明文は日本語で書いてあり、英語表示のときは `Showroom.tsx` の `describePage` が書き換えます。

## 展示物を増やす

1. `content.ts` の該当事業の `items` に項目を追加する（名前や説明は `t(...)` で2言語とも書く）
2. `items.ts` の `builders` に `事業ID/項目ID` のキーで形を追加する（未登録の項目は仮の箱で表示されます）
